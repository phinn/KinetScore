KinetScore

为 iPhone Duo 而生的乐谱阅读器 · 双页对开 · 半开练习 · 内置节拍器

它解决什么

练琴时纸质谱页翻动麻烦、平板支架占地。KinetScore 把折叠屏手机变成双页谱架:展开看对开乐谱,半开立起当谱面,合盖自动书签。纯本地,导入你自己的 PDF 乐谱即可使用。

核心功能

  • 双页对开 — 展开手机,左右两页并排呈现,和印刷谱一致
  • 半开练习模式 — 乐谱在上、控制台在下,演奏中页面不误翻
  • 内置节拍器 — 不离开乐谱打响节拍,一键调速
  • 合盖书签 — 合上手机,外屏显示曲名、页码与速度,翻开即续读
  • 纯本地 — 无账号、无上传、无追踪
